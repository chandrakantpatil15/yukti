# Yukti React Dashboard

Modern React + TypeScript dashboard for AWS cost optimization.

## 🚀 Tech Stack

- **React 18** - Latest React with concurrent features
- **TypeScript** - Type safety and better DX
- **Vite** - Fast build tool and dev server
- **Tailwind CSS** - Utility-first CSS framework
- **React Query** - Smart data fetching and caching
- **Chart.js** - Interactive charts
- **Axios** - HTTP client

## 🛠️ Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 📱 Features

- **Real-time data** with auto-refresh
- **Responsive design** for all devices
- **TypeScript** for type safety
- **Smart caching** with React Query
- **Modern UI** with Tailwind CSS
- **Fast development** with Vite HMR

## 🔗 API Integration

The dashboard connects to Spring Boot backend at `http://localhost:8081/api`

## 📊 Components

- `Dashboard` - Main dashboard layout
- `MetricCard` - Reusable metric display
- `CostChart` - Chart components
- Custom hooks for data fetching

Access at: http://localhost:3000
